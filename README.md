# Private Events

This project is meant to provide an opportunity to practice with many-to-many
associations in Rails. See the
[project assignment](https://www.theodinproject.com/lessons/ruby-on-rails-private-events#assignment)
at The Odin Project. The goal is to build a service similar to a private
[Eventbrite](https://www.eventbrite.com/) where users can organize and attend many
events.
